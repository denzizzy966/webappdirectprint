⚖️ Hardware Bridge — Panduan Integrasi Web (Laravel / ERPNext)

Klien JavaScript serbaguna tanpa dependensi untuk membaca Timbangan Digital (RS232/Serial) dan melakukan Silent Direct Print (ESC/POS, ZPL, PDF) langsung dari browser ke printer kasir/gudang via Hardware Bridge lokal (http://127.0.0.1:18212).

Status Hardware Bridge di PC ini: memeriksa...

1. Prasyarat & Instalasi

  1. Hardware Bridge berjalan di PC klien (ikon system tray hijau / port 18212).
    Windows: jalankan HardwareBridge.exe atau install service. Linux: sudo systemctl start hardware-bridge.
  2. Origin HTTP di Chrome/Edge: Jika aplikasi Laravel/ERPNext diakses via protokol http:// (misal IP lokal http://192.168.1.10:8000), jalankan allow-private-network.reg sekali pada PC klien agar browser tidak memblokir koneksi ke 127.0.0.1. Jika situs diakses lewat https://, bridge otomatis mendukung enkripsi WSS/HTTPS.

2. Pasang di Laravel Blade

Salin hardware-bridge.js (atau timbangan-service.js) ke direktori public/js/ project Laravel Anda, lalu pasang di layout Blade:

<!-- resources/views/layouts/app.blade.php -->
<script src="{{ asset('js/hardware-bridge.js') }}"></script>

💡 Catatan: Objek global HardwareBridge dan TimbanganSvc adalah identik (100% kompatibel). Anda dapat memakai salah satu nama tanpa merubah kode yang sudah ada.

3. Menentukan Timbangan Apabila Ada 2 (atau Lebih) yang Aktif

Di area kasir atau gudang seringkali terdapat 2 timbangan sekaligus pada 1 PC, misalnya:
• Timbangan Gram (Presisi) terhubung ke COM5
• Timbangan Koli / Duduk (Kapasitas Besar) terhubung ke COM3

Keduanya dikonfigurasi pada file bridge_config.json: 

"scales": [
  { "name": "Timbangan Gram", "port": "COM5", "protocol": "mettler", "baud": 9600 },
  { "name": "Timbangan Koli", "port": "COM3", "protocol": "shinko",  "baud": 9600 }
]

4 Cara Menentukan Timbangan Mana yang Digunakan:

Cara A — Parameter Langsung di Kode (Direct Parameter)

Gunakan opsi { scale: 'Nama Timbangan' } atau { scale: 'COM5' }. Sistem pencocokan bersifat cerdas: mencocokkan Nama Lengkap, Case-Insensitive, Nomor Port (COM5 / /dev/ttyUSB0), atau Substring kata kunci (misal 'gram' atau 'koli'). 

// Tombol Timbang Gram (presisi perhiasan / sparepart kecil)
HardwareBridge.timbangKeInput('#berat_gram', { scale: 'Timbangan Gram' });

// Tombol Timbang Koli (paket dus karton)
HardwareBridge.timbangKeInput('#berat_koli', { scale: 'Timbangan Koli' });

// Atau langsung menggunakan nomor port COM
HardwareBridge.timbangKeInput('#berat', { scale: 'COM5' });

Cara B — Dropdown Dinamis Pilihan Operator (Interactive Dropdown)

Sediakan elemen <select id="pilihTimbangan"></select> di form Anda. SDK menyediakan fungsi populateScaleSelect untuk mengisinya secara otomatis dengan seluruh timbangan yang sedang terhubung: 

<select id="pilihTimbangan"></select>
<button type="button" onclick="ambilDariPilihan()">⚖️ Timbang Sesuai Pilihan</button>

<script>
  // Otomatis isi dropdown dengan timbangan yang sedang online:
  HardwareBridge.populateScaleSelect('#pilihTimbangan');

  function ambilDariPilihan() {
    const scaleDipilih = document.querySelector('#pilihTimbangan').value;
    HardwareBridge.timbangKeInput('#berat_target', {
      scale: scaleDipilih,
      alerts: true
    });
  }
</script>

Cara C — Dialog Pop-up dengan Saklar Terintegrasi (timbangDialog)

Fungsi HardwareBridge.timbangDialog() secara otomatis mendeteksi jika ada lebih dari 1 timbangan aktif, lalu menampilkan pemilih timbangan langsung di dalam modal pop-up sehingga kasir/operator dapat berganti timbangan hanya dengan 1 klik! 

HardwareBridge.timbangDialog(function (gram, scaleObj) {
    console.log("Diambil dari:", scaleObj.name, "Hasil:", gram);
    document.querySelector('#berat').value = gram.toFixed(2);
});

Cara D — Otomatis (Auto Fallback)

Jika parameter scale tidak diisi (atau bernilai null), sistem secara otomatis memilih timbangan fisik pertama yang berstatus connected: true (mengabaikan Simulator Virtual).

4. timbangKeInput(target, opts) — Ambil Nilai STABIL

Fungsi utama untuk memasukkan data berat yang telah STABIL ke dalam elemen <input>.

<input type="text" id="berat" name="berat">
<button type="button" onclick="HardwareBridge.timbangKeInput('#berat')">⚖️ Timbang</button>

// Dengan opsi lengkap:
HardwareBridge.timbangKeInput('#berat', {
    scale: 'Timbangan Gram', // Nama / Port timbangan (null = otomatis)
    alerts: true,            // Tampilkan toast status progres & sukses
    stable_timeout: 10,      // Waktu tunggu stabil maksimal (detik)
    decimals: 2,             // Jumlah angka di belakang koma (default: 2)
    to_gram: true            // Konversi otomatis kg/mg ke gram (default: true)
});
OpsiDefaultPenjelasan
scalenull (auto)Nama timbangan dari config atau port (misal 'Timbangan Gram', 'COM5')
alertsfalseMenampilkan pesan toast mengambang saat proses membaca stabil
stable_timeout10Batas maksimal menunggu timbangan stabil (dalam detik)
decimals2Presisi angka desimal hasil timbang
to_gramtrueOtomatis konversi satuan ke gram (kg dikali 1000, mg dibagi 1000)

✅ Kompatibilitas Form Reaktif: Fungsi ini memicu event JavaScript standar input dan change dengan bubbles: true. Oleh karena itu, Laravel Livewire (wire:model), Vue.js (v-model), dan React akan langsung ter-update tanpa perlu mengetik ulang!

5. liveWeight(target, opts) — Tampilan Berat Live Real-Time

Menampilkan angka berat yang terus diperbarui secara langsung (default interval 500ms):

<span id="berat-live">--</span>

    scale: 'Timbangan Gram',
    decimals: 2,
    suffix: ' g'
  });

  // Jika ingin menghentikan stream pembacaan:
  // stopLive();
</script>

6. timbangDialog(onUse, opts) — Modal Interaktif Lengkap

Membuka pop-up modal bersih dengan display angka besar dan tombol "Gunakan Berat (stabil)":

HardwareBridge.timbangDialog(function (gram, scale) {
    alert("Diterima dari " + scale.name + ": " + gram + " gram");
    document.querySelector('#berat_input').value = gram.toFixed(2);
}, {
    title: '⚖️ Timbang Material Emas / Paket',
    stable_timeout: 10
});

7. Silent Direct Printing (Cetak Struk ESC/POS & Faktur PDF)

Mencetak dokumen langsung ke printer tanpa memunculkan dialog pencetakan browser:

// 1. Ambil daftar printer yang terhubung ke PC
const printerList = await HardwareBridge.getPrinters();
console.log("Printer terpasang:", printerList.printers);

// 2. Silent Print Struk Thermal Kasir (ESC/POS)
await HardwareBridge.printRaw("EPSON TM-T82", "\x1B\x40TOKO SUKSES\nTotal: Rp 50.000\n\n\x1D\x56\x00");

// 3. Silent Print Dokumen PDF (Faktur / Label Barcode)
// Bisa berupa data Base64 maupun URL dokumen
await HardwareBridge.printPdf("Godex G500", "data:application/pdf;base64,JVBERi0xLjQK...");

// 4. Buka Cash Drawer Laci Kasir
await HardwareBridge.openCashDrawer("EPSON TM-T82");

<!-- resources/views/livewire/transaksi-penjualan.blade.php -->
<div class="p-4 bg-white rounded shadow">
    <h3>Form Penimbangan Barang</h3>

    <!-- Input Berat dengan Livewire wire:model -->

        <label>Berat Barang (Gram)</label>
        <div class="input-group">
            <input type="text" id="input-berat" wire:model="berat_bersih" class="form-control">
            <button type="button" class="btn btn-primary" onclick="lakukanTimbang()">
                ⚖️ Timbang Otomatis
            </button>
        </div>
        <small class="text-muted">
            Live: <b id="live-display">--</b> &bull; Status: <span id="bridge-status"></span>
        </small>
    </div>
</div>

<script src="{{ asset('js/hardware-bridge.js') }}"></script>
<script>
document.addEventListener('DOMContentLoaded', function () {
    // 1. Tampilkan status koneksi service
    HardwareBridge.attachIndicator('#bridge-status');

    // 2. Isi dropdown timbangan (Timbangan Gram / Koli)
    HardwareBridge.populateScaleSelect('#pilih-timbangan', {
        onChange: function (selectedScale) {
            // Restart live reading sesuai timbangan yang dipilih
            HardwareBridge.liveWeight('#live-display', { scale: selectedScale });
        }
    });

    // 3. Mulai live reading default
    HardwareBridge.liveWeight('#live-display');
});

function lakukanTimbang() {
    const scaleName = document.querySelector('#pilih-timbangan').value;
    HardwareBridge.timbangKeInput('#input-berat', {
        scale: scaleName,
        alerts: true,
        decimals: 2
    });
}
</script>
