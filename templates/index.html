1. Kamus Fungsi JavaScript SDK (HardwareBridge / TimbanganSvc)

Muat script di HTML: <script src="http://127.0.0.1:18212/static/js/hardware-bridge.js"></script>. Berikut daftar fungsi yang dapat dipanggil:

Nama Function Parameter & Opsi Kegunaan & Nilai Kembalian
HardwareBridge.timbangKeInput(target, opts) target: Selector CSS / elemen (misal '#berat')
opts: { scale, stable_timeout, decimals, to_gram, alerts, allow_zero } 		(Sangat Populer) Mengunci berat STABIL lalu otomatis mengisi nilai ke elemen <input>. Memancarkan event input & change (bubbles) sehingga langsung terdeteksi oleh Livewire (wire:model), Vue (v-model), dan React.
HardwareBridge.liveWeight(target, opts) target: Selector CSS / elemen teks
opts: { scale, interval, decimals, suffix, to_gram, onUpdate } 		Menampilkan angka berat real-time yang terus berubah mengikuti pergerakan timbangan. Mengembalikan fungsi stop() untuk menghentikan interval.
HardwareBridge.stableRead(scale, timeoutS) scale: Nama/port timbangan (atau null untuk auto)
timeoutS: Batas waktu tunggu stabil dalam detik (default: 10) 		Promise async: Menunggu timbangan menghasilkan data yang STABIL. Mengembalikan object: { ok: true, weight: 125.4, unit: 'g', stable: true, elapsed_seconds: 1.2 }.
HardwareBridge.getWeight(scale) scale: Nama timbangan (misal 'Shinko 1', '/dev/ttyUSB0', atau null) Mengambil berat terkini secara instan (non-blocking). Mengembalikan object: { status: 'success', weight: 125.4, unit: 'g', stable: true, age: 0.1 }.
HardwareBridge.listScales() Tanpa parameter Mengambil daftar seluruh timbangan yang terdaftar di bridge beserta status online/offline-nya dalam bentuk array JSON.
HardwareBridge.pickScale(preferred) preferred: Nama / port / substring pencocokan Algoritma cerdas untuk memilih timbangan aktif. Jika preferred kosong, otomatis memilih timbangan fisik pertama yang tersambung (bukan virtual SIM).
HardwareBridge.populateScaleSelect(sel, opts) sel: Selector elemen <select>
opts: { selected, onChange } 		Mengisi elemen dropdown <select> dengan daftar timbangan aktif secara otomatis. Sangat praktis jika di meja kasir terdapat 2 timbangan.
HardwareBridge.timbangDialog(onUse, opts) onUse: function(gram, unit, scale)
opts: { scale, title } 		Menampilkan pop-up modal interaktif mandiri yang menampilkan live weight, status stabil, tombol "Gunakan Berat", dan dropdown multi-timbangan jika ada 2 timbangan.
HardwareBridge.zero(scale) scale: Nama/port timbangan (opsional) Mengirim perintah Zero (0.00) ke sensor timbangan.
HardwareBridge.tare(scale) scale: Nama/port timbangan (opsional) Mengirim perintah Tare (Wadah/Tara) ke sensor timbangan.
HardwareBridge.attachIndicator(target) target: Selector badge (misal '#status-timbangan') Menampilkan status koneksi 🟢 Online, 🟡 Sim, atau 🔴 Offline secara periodik otomatis.
HardwareBridge.pause(scale, sec) scale: Nama/port, sec: durasi detik (default 30) Melepas port serial sementara agar dapat dibuka oleh aplikasi lain (misal Delphi atau Chrome Web Serial).
HardwareBridge.resume(scale) scale: Nama/port timbangan Mengambil alih dan menyambungkan kembali port serial setelah dipakai software lain.

2. Contoh Kode Universal Web (HTML / Vanilla JS / Laravel / Vue / React)

Contoh A: 1-Klik Timbang ke Form Input (Laravel Blade / Livewire / Vue / React)

Operator menekan tombol "⚖️ Ambil Berat", bridge akan menunggu pembacaan stabil dan otomatis menuliskan angka ke <input id="berat">: 

<!-- Input dan Tombol Timbang -->
<div style="display: flex; gap: 8px;">
  <input type="number" id="berat" name="berat" step="0.01" placeholder="0.00">
  <button type="button" class="btn btn-primary" onclick="ambilBerat()">⚖️ Ambil Berat</button>
</div>

<script src="http://127.0.0.1:18212/static/js/hardware-bridge.js"></script>
<script>
async function ambilBerat() {
  // timbangKeInput otomatis menunggu nilai STABIL dan menembakkan event input/change
  const hasil = await HardwareBridge.timbangKeInput('#berat', {
    scale: 'Shinko 1',   // Bisa spesifik 'Shinko 1', 'COM3', atau null (otomatis)
    stable_timeout: 6,    // Maksimal tunggu 6 detik
    decimals: 2,          // 2 digit desimal (misal 12.50)
    alerts: true          // Tampilkan notifikasi toast progres & sukses
  });

  if (hasil) {
    console.log('Berat berhasil dimasukkan:', hasil, 'gram');
  }
}
</script>

3. Cara Pasang di ERPNext (Client Script Form & Child Table)

Di ERPNext, Anda dapat menggunakan Client Script pada DocType apapun (misal POS Invoice, Sales Invoice, Purchase Receipt, atau Stock Entry).

Kasus 1: Tombol Timbang Otomatis pada Baris Tabel Barang (Child Table items)

Operator menimbang barang, klik tombol timbang di baris item, berat stabil langsung masuk ke kolom qty atau custom_berat: 

// Target DocType: POS Invoice (atau Purchase Receipt / Stock Entry)
const BRIDGE_URL = 'http://127.0.0.1:18212';

// 1. Tombol di Header Form
frappe.ui.form.on('POS Invoice', {
    refresh: function(frm) {
        // Tombol Ambil Berat Form Header
        frm.add_custom_button(__('⚖️ Timbang Item Aktif'), function() {
            ambilBeratTimbangan(frm);
        }, __('Aksi Timbangan'));

        // Tombol Zero (0.00)
        frm.add_custom_button(__('0️⃣ Zero Timbangan'), function() {
            fetch(`${BRIDGE_URL}/api/scale/zero`, { method: 'POST' })
                .then(() => frappe.show_alert({ message: __('Timbangan di-Zero (0.00)'), indicator: 'green' }));
        }, __('Aksi Timbangan'));

        // Tombol Tare (Wadah)
        frm.add_custom_button(__('⚖️ Tare (Wadah)'), function() {
            fetch(`${BRIDGE_URL}/api/scale/tare`, { method: 'POST' })
                .then(() => frappe.show_alert({ message: __('Timbangan di-Tare'), indicator: 'green' }));
        }, __('Aksi Timbangan'));
    }
});

// 2. Tombol di Baris Child Table (Item)
frappe.ui.form.on('POS Invoice Item', {
    // Dipicu jika Anda membuat Custom Field bertipe Button dengan fieldname 'btn_timbang' di child table
    btn_timbang: function(frm, cdt, cdn) {
        frappe.show_alert({ message: __('Menunggu berat stabil...'), indicator: 'blue' });

        // Panggil endpoint stable-read bridge
        fetch(`${BRIDGE_URL}/api/scale/stable-read?timeout=5.0`, { method: 'POST' })
            .then(res => res.json())
            .then(res => {
                if (res.status === 'success' || res.ok) {
                    const berat = Number(res.data.weight);
                    // Masukkan berat ke kolom Qty baris item saat ini
                    frappe.model.set_value(cdt, cdn, 'qty', berat);
                    frappe.show_alert({
                        message: `✅ Berat Terkunci: ${berat} ${res.data.unit}`,
                        indicator: 'green'
                    });
                } else {
                    frappe.msgprint(__('Timbangan belum stabil: ') + (res.message || res.error));
                }
            })
            .catch(() => {
                frappe.msgprint(__('Gagal menghubungi Hardware Bridge di ') + BRIDGE_URL);
            });
    }
});

function ambilBeratTimbangan(frm) {
    frappe.show_alert({ message: __('Membaca timbangan... Harap tunggu stabil'), indicator: 'blue' });
    fetch(`${BRIDGE_URL}/api/scale/stable-read?timeout=5.0`, { method: 'POST' })
        .then(r => r.json())
        .then(res => {
            if (res.status === 'success' || res.ok) {
                frappe.msgprint({
                    title: __('Hasil Pembacaan Timbangan'),
                    indicator: 'green',
                    message: `Berat: <b style="font-size: 1.3rem; color: #10b981;">${res.data.weight} ${res.data.unit}</b><br>Timbangan: <b>${res.data.name}</b> (${res.data.port})`
                });
            } else {
                frappe.msgprint(__('Timbangan belum stabil: ') + res.message);
            }
        });
}
Kasus 2: Memilih Antara 2 Timbangan (Shinko 1 vs Shinko 2) di ERPNext

Gunakan parameter scale pada URL untuk mengarahkan pembacaan ke timbangan tertentu: 

// Membaca Timbangan Gram (Shinko 1)
fetch('http://127.0.0.1:18212/api/scale/stable-read?scale=Shinko%201&timeout=4.0', { method: 'POST' })
    .then(r => r.json())
    .then(res => console.log('Shinko 1:', res.data.weight));

// Membaca Timbangan Koli (Shinko 2)
fetch('http://127.0.0.1:18212/api/scale/stable-read?scale=Shinko%202&timeout=4.0', { method: 'POST' })
    .then(r => r.json())
    .then(res => console.log('Shinko 2:', res.data.weight));

4. Hook POS Checkout Otomatis (POS Awesome & ERPNext POS)

Script ini mendengarkan event submit POS invoice untuk langsung mencetak struk thermal dan menendang laci uang saat kasir selesai memproses pembayaran: 

$(document).on('pos_invoice_submitted', function(event, invoice_doc) {
    if (!invoice_doc) return;

    // 1. Buka laci kasir otomatis
    fetch('http://127.0.0.1:18212/api/cashdrawer/open', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ pin: 2 })
    }).catch(() => {});

    // 2. Format Struk Thermal ESC/POS
    let receipt = "\x1b\x40\x1b\x61\x01\x1d\x21\x11" + (invoice_doc.company || "STRUK KASIR") + "\n\x1d\x21\x00";
    receipt += "----------------------------------------\n\x1b\x61\x00";
    receipt += "No: " + invoice_doc.name + "\n";
    receipt += "Tgl: " + invoice_doc.posting_date + "\nKasir: " + (invoice_doc.owner || "") + "\n----------------------------------------\n";

    (invoice_doc.items || []).forEach(item => {
        receipt += `${item.qty}x ${item.item_name} - ${Number(item.amount).toLocaleString('id-ID')}\n`;
    });

    receipt += "----------------------------------------\n\x1b\x61\x02";
    receipt += "TOTAL: Rp " + Number(invoice_doc.grand_total).toLocaleString('id-ID') + "\n";
    receipt += "----------------------------------------\n\x1b\x61\x01";
    receipt += "Terima Kasih!\n\n\n\x1d\x56\x42\x00";

    // 3. Kirim ke Bridge lokal di PC Kasir
    fetch('http://127.0.0.1:18212/api/print/raw', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ data: receipt, doc_name: invoice_doc.name })
    }).catch(err => console.warn('Gagal print POS:', err));
});

5. Kamus REST API & cURL (Untuk Backend Python / PHP / C# / Postman)

Method Endpoint Parameter Deskripsi
GET /api/scales none Daftar seluruh timbangan beserta status koneksi, baudrate, dan port.
GET /api/weight ?scale=Shinko%201 Mengambil berat saat ini (instan, non-blocking). Format: { weight, unit, stable, age }.
POST /api/scale/stable-read ?scale=...&timeout=5.0 Menunggu hingga berat STABIL terkunci. Mengembalikan { ok: true, weight, unit, elapsed_seconds }.
POST /api/scale/zero ?scale=Shinko%201 Mengirim perintah Zero (0.00) ke timbangan.
POST /api/scale/tare ?scale=Shinko%201 Mengirim perintah Tare (Wadah) ke timbangan.
POST /api/scale/command JSON: {"scale":"...","command":"O9"} Mengirim perintah serial mentah (raw command: O9, O8, SI, S, Z, dll).
POST /api/scale/pause ?scale=...&seconds=30 Melepas port serial untuk dipakai Delphi atau software lain.
GET /api/stream none Stream SSE (Server-Sent Events) untuk menerima berat real-time terus-menerus. 
# 1. Ambil daftar timbangan terdaftar
curl -X GET http://127.0.0.1:18212/api/scales

# 2. Ambil berat instan dari Shinko 1
curl -X GET "http://127.0.0.1:18212/api/weight?scale=Shinko%201"

# 3. Tunggu berat stabil (timeout 5 detik)
curl -X POST "http://127.0.0.1:18212/api/scale/stable-read?scale=Shinko%201&timeout=5.0"

# 4. Kirim Zero & Tare
curl -X POST "http://127.0.0.1:18212/api/scale/zero?scale=Shinko%201"
curl -X POST "http://127.0.0.1:18212/api/scale/tare?scale=Shinko%201"

# 5. Kirim perintah manual (misal O9 untuk Shinko)
curl -X POST http://127.0.0.1:18212/api/scale/command \
  -H "Content-Type: application/json" \
  -d '{"scale": "Shinko 1", "command": "O9"}'
